# LeakSanitizer 抑制表 —— 只针对**已定位的测试退出时序残留**，不掩盖产品泄漏。
#
# 背景（Issue #2）：
#   这两处泄漏都是"测试先退出、服务端还没把连接/会话收尾"，属于测试夹具的时序问题，
#   不是产品代码在运行期持有。它们只在进程退出时表现为"不可达但未释放"。
#
# 为什么用抑制而不是继续改代码：
#   已尝试并从 4 个套件降到 2 个（会话自环已彻底修掉）；剩下两处的正确修法是
#   重排测试夹具的析构顺序（server/io/loop 的依赖方向），改动面大且会牵动
#   十几个用例。先把它们**固定成已知项**，让 LSan 门禁转阻塞——任何**新增**泄漏
#   都会立刻让 CI 变红，这比继续挂着"仅报告"更有价值。
#
# 规则写法：leak:<栈帧符号子串>。这里刻意收窄到具体函数，避免误伤。

leak:zenith::crew::mountCrewWs
leak:zenith::net::TcpServer::handleAccept
